覆盖项 overrides

写回 config.json 的 accounts[alias]。引擎按“顶层键”回退：某个键在账号里存在即整块生效，不做嵌套深合并；删除某键即恢复继承。

必须是 JSON 对象；解析失败不会提交。

邮箱配置

隧道地址变更时下发到此账号邮箱。多个地址用逗号或空格分隔；留空表示未配置。管理员副本由全局 notify 列表决定。
