# PRD（C2）：免费/可用图像模型普查与封面链接入

> 父任务：`10-20-ops-resilience-upgrade`（执行顺序 #2，可与 C1 并行，但排在 C1 之后启动）

## 问题陈述

每日图文封面现用 `cover.ai` 链：`cn:hunyuan-image-alpha-edit`（15–21s）→ `global:gpt-image-2.5-sunburst`（~35s），见 `src/cover-ai.ts:439-440`。用户希望知道**互联网上还有哪些免费/可用的 gpt-image-2.5 及更强的图像模型**，用于每日图文生成。

### 已采集事实（2026-10-20，真实请求）

| # | 事实 | 证据 |
|---|---|---|
| E1 | 250 网关（`meta-gateway` → `127.0.0.1:3011/v1`）共 **99** 个模型，其中图像类 **7** 条（去重后 5 个） | `GET /v1/models`（Bearer，99 条） |
| E2 | 可用图像模型全集：`cn:hunyuan-image-alpha-edit`、`cogview-3-flash`、`cogview-4`、`cogview-4-250304`、`global:gpt-image-2.5-sunburst`（另有 `workbuddy/` 前缀的两条同源镜像） | 同上 |
| E3 | 网关**没有** gpt-image-2.5 以上的图像模型（gpt-image-3 / imagen-4 均未出现）；`gpt-5.x/6.x` 存在但都是**文本**模型 | 同上（`gpt-*` 全量列表） |
| E4 | `cogview-3-flash` / `cogview-4` 系列**从未被本项目的 `cover.ai` 链使用过**，也从未实测延迟/尺寸/费用 | 当前链仅 2 个模型 |
| E5 | 已有探测能力：`listImageModels()`（`src/cover-ai.ts:326-340`）可枚举过滤；`cover-selftest` 46 项断言可扩展 | 代码 |
| E6 | 图像模型会"吸尺寸"（请求 900×383 实测回 896×368），已由 `fitImageTo()` 二次裁切兜底 | 10-20 变更日志 |

## 需求

- **R1 网关内普查（实测优先）**：对 E2 全部图像模型逐个真实出图（900×383，同一份简报），记录：HTTP 状态 / 首字节与总耗时 / 实际返回尺寸 / 是否吸附 / 是否画出文字或数字 / 失败原因与可重试性。
- **R2 外部免费源清单**：整理并标注**可实测性**（是否需要注册、是否需信用卡、是否有免费额度、是否支持商用），至少覆盖：Cloudflare Workers AI、智谱 CogView-flash、SiliconFlow、ModelScope、Gemini 免费层、Pollinations 等。**每条必须有官方文档链接 + 实测步骤**，禁止"据说"。
- **R3 选型矩阵文档**：`docs/research/image-models.md` —— 维度：模型 / 来源 / 成本 / 延迟 / 尺寸支持 / 中文字形能力 / 稳定性 / 是否需外网代理 / 推荐用途（每日主力 / 兜底 / 备用）。
- **R4 接入与降级**：按实测结果更新 `cover.ai.model` + `fallbacks`（保持 AI → ffmpeg → template 三级降级与"绝不阻断发布"）；`doctor` 新增 `cover-candidates` 行（列出可用图像模型与最近一次成功/失败时间）。
- **R5 质量评测**：扩展 `tools/cover-selftest.ts`，对候选模型做**简报符合度**的小样本评分（是否画出数字/文字 = 硬扣分；是否用指定深底+强调色 = 检查），避免"能出图但没法用"。
- **R6 成本护栏**：每日封面生成次数上限 + 免费额度耗尽自动降级（记录到日志/邮件，不静默）。

## 验收标准

- [ ] **AC1 实测矩阵完成**：E2 的每个模型都有真实出图产物（PNG 落盘路径）+ 延迟/尺寸/状态记录；失败的写明原因。
- [ ] **AC2 外部源清单可执行**：`docs/research/image-models.md` 中每个外部候选都有官方链接与「如何验证」两条命令，且标注是否需要用户注册（Q3 放行项）。
- [ ] **AC3 链路落地**：`cover.ai.model/fallbacks` 按矩阵更新；故障注入（不存在的模型 / 断网网关）后仍能降级到 ffmpeg 且 `publish --dry-run` 成功。
- [ ] **AC4 自检生效**：`doctor --all` 出现 `cover-candidates` 行且内容真实（不能是硬编码）。
- [ ] **AC5 质量门**：`cover-selftest` 新增简报符合度断言全部通过；至少 1 张真机封面人工目视认可（无错字/无乱码/无数字）。
- [ ] **AC6 零回退**：无新增运行时依赖；`bun build`/`tsc` 通过；250 当天发布仍 `✅ 正文校验`。

## 开放决策

| # | 问题 | 建议 |
|---|---|---|
| Q3 | 是否允许真实调用外部免费图像 API（可能需注册/占用额度） | 先完成 R1（网关内、零外部依赖），再把外部源作为「清单 + 验证步骤」交付；每个外部源由用户单独放行后再实测 |

## 非目标

- 不接入需要付费订阅、或无法在 250 上稳定直连的图像服务作为**默认**主力模型。
- 不改动封面的确定性裁切/落盘逻辑（`fitImageTo`/`parseSize`/`imageSize`），那部分是已验证的。
